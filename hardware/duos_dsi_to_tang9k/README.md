# Duo S MIPI DSI -> Tang Nano 9K

Generated by `gen_project.py` (re-run to regenerate). Open `duos_dsi_to_tang9k.kicad_pro` in KiCad 7+.
Network diagram: `dphy_full_lp_network.png`.

## Connectors
- **J1** = Duo S CON26A (2x13). pair0=D0 (1/3), pair1=D1 (2/4), pair2=CLK (7/9); D2/D3 unused.
- **J2** mirrors Tang Nano 9K header J6 (pin n = pin n), **J3** mirrors header J5.

| Signal | Tang pin | Header pin | Bank/IO |
|---|---|---|---|
| HS_CK_P / N | 80 / 79 | J6-8 / J6-9 | IOT12A/B, 1.8 V LVDS |
| HS_D0_P / N | 82 / 81 | J6-6 / J6-7 | IOT11A/B, 1.8 V LVDS |
| HS_D1_P / N | 84 / 83 | J6-4 / J6-5 | IOT10A/B, 1.8 V LVDS |
| LP_D0_P | 85 | J6-3 | IOT8B, 1.8 V LVCMOS |
| LP_CK_P (via level shifter) | 25 | J5-5 | IOB8A, 3.3 V |
| LP_D1_P (via level shifter) | 26 | J5-6 | IOB8B, 3.3 V |

J2 pin 23 = GND and pin 24 = 3V3 are used for the level shifters and VCM bias.

## Receive network (per lane)
- 2x50R + 100nF split termination: 100R differential at HS, DC-open so LP levels are not loaded.
- HS AC-coupled (100nF) to the LVDS pair, biased to VCM 0.9 V (27k/10k divider from 3V3).
- 470R LP tap from DSI_x_P. CK and D1 go through SN74AUP1T17 (3.3 V supply) to the 3.3 V pins; D0 goes straight to pin 85.
- 2-layer, 0.8 mm, GND pour on B.Cu; `DSI_*`/`HS_*` are in net class MIPI_DPHY_100R (0.25/0.2 mm starting values - verify).

## Must verify before fab
1. SN74AUP1T17: check the datasheet that VT+ (max) at VCC=3.3 V is below the D-PHY LP-high level (>= 0.88 V RX spec). Pick another low-threshold part if not.
2. `ROW_PITCH` (J2<->J3 spacing, 17.78 mm assumed) and pin-1 orientation vs your Tang Nano 9K. Use female sockets.
3. Confirm in the Gowin pin list that IOT10/11/12 A/B are true LVDS _T/_C pairs and that LVDS input at 1.8 V VCCO with 0.9 V common mode is allowed.
4. Lane map matches the SDK 2-lane panel config {LANE_0, LANE_1, LANE_CLK}; swap `lane_pn_swap` in `cvi_mpi/component/panel/cv181x/*.h` if routing ends up crossed.
5. Generated without KiCad available: open, run ERC/DRC (expect 3V3/GND power-flag warnings), route, re-save.
